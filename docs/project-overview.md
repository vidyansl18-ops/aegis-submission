# Project Overview

**Aegis FinOps** is a simulated autonomous FinOps control plane.

The central idea is simple:

> The model decides what evidence to investigate and proposes a bounded action; deterministic backend code decides whether the action is allowed; the simulator executes it; fresh state proves what happened.

The UI is designed for live competition demonstrations and includes a dedicated Data Studio so judges can provide new JSON inputs instead of being limited to hardcoded scenarios.
